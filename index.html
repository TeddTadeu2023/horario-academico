1
Cadastrar Salas & Espaços
Aba: Salas → Botão: + Nova Sala

Cadastre todos os espaços físicos disponíveis — salas de aula, laboratórios, oficinas, auditórios. O sistema usa essas informações para detectar conflitos de sala automaticamente entre todos os planos.

🏫 Exemplo de salas cadastradas
💻 Lab. Informática A
Laboratório · 30 alunos · Bloco B · 30 PCs, Projetor
8 aulas
🏫 Sala 201
Sala de Aula · 40 alunos · Bloco A · Projetor, Ar-cond.
5 aulas
🔧 Oficina Mecânica
Oficina · 25 alunos · Bloco C · Bancadas, Ferramentas
3 aulas
💡 Dica: Preencha a capacidade e os recursos de cada sala. Isso facilita a escolha do espaço ideal na hora de alocar as aulas.
2
Cadastrar Docentes
Aba: Docentes → Botão: + Novo Docente

Cadastre cada professor uma única vez. O campo de Disciplinas que leciona é incremental — escreva o nome e pressione Enter para adicionar como tag. Um mesmo docente pode ser alocado em múltiplos cursos e planos.

👤 Campo de disciplinas — entrada incremental por tags
Algoritmos × Estrutura de Dados × Python ×
Digite uma disciplina e pressione Enter…
💡 Importante: O sistema bloqueia o mesmo docente em dois horários simultâneos — mesmo em planos diferentes. Cadastre cada professor apenas uma vez.

Aba: Cursos → Botão: + Novo Curso

Cadastre cada curso com suas informações acadêmicas. Os dados aqui serão usados automaticamente ao criar um Plano de Horário — sem cursos cadastrados, não é possível criar planos.

4
Configurar o Turno
Painel lateral → Seção: Turno

Antes de criar o plano e alocar aulas, configure o turno no painel lateral. Selecione Manhã, Tarde ou Noite — os horários de cada aula carregam automaticamente. Você pode editar o início e fim de cada aula individualmente.

⏰ Configuração do turno na barra lateral

💡 Use os botões + e − para adicionar ou remover aulas do turno. Os horários configurados aqui definem as linhas disponíveis na grade.
5
Criar Plano de Horário
Aba: Grade → Botão: 📄 Novo Plano

Cada Plano é uma turma com grade própria. Selecione o curso no dropdown — os campos se preenchem automaticamente. Como coordenador, crie um plano para cada turma. Os planos aparecem como abas na grade.

📄 Abas de planos — cada aba é uma turma
ADS · 3º Sem · 2026 8 aulas Mecânica · 1º Sem 6 aulas ＋ Novo Plano
Clique para alternar · Duplo clique para editar · × para excluir o plano
💡 O plano herda a cor do curso selecionado. Docentes e salas são compartilhados — conflitos entre planos são detectados automaticamente.
6
Alocar Aulas na Grade
Clique em qualquer célula vazia · ou Botão: + Alocar Aula

Clique em qualquer célula da grade para abrir o modal de alocação. Selecione múltiplos horários via checkboxes, escolha o curso, docente e sala. Horários com conflito são bloqueados automaticamente.

📋 Seleção de múltiplos horários por checkboxes
✔ Marcado — horário livre, será alocado
☐ Desmarcado — disponível mas não selecionado
🔴 Prof. ocupado / Sala ocupada — bloqueado
💡 Ao trocar o docente ou a sala no formulário, os checkboxes atualizam automaticamente mostrando quais horários ficam bloqueados para aquela combinação.
7
Revisar, Resumir e Exportar
Botões: 📊 Resumo · Conflitos · ⬇ Exportar JSON
📊
Resumo
Visão macro de todos os planos. Filtre por professor para ver sua grade semanal completa.
⚠️
Conflitos
Lista todos os conflitos entre planos. O badge vermelho no menu indica o total ativo.
💾
Exportar / Importar
Salve o planejamento completo em JSON. Importe para continuar em outra sessão ou computador.
✅
Pronto! Com todos os passos concluídos, sua grade estará sem conflitos e pronta. Use Resumo → 🖨 Imprimir para gerar um PDF com todas as grades ou ⬇ Exportar JSON para salvar e compartilhar o planejamento.
